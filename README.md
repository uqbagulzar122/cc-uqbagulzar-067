🧪 Lab Overview
This lab introduces the basics of virtualization using VMware Workstation Pro and demonstrates how to create and configure a virtual machine (VM) running Ubuntu Server. Students learn to establish SSH connections between Windows and Ubuntu environments.

🧰 Tools & Technologies
VMware Workstation Pro (for virtualization)

Ubuntu Server (as the guest operating system)

Windows OS (as the host)

SSH (Secure Shell) (for remote connection)

🧩 Lab Tasks
1. Installing VMware Workstation Pro
Downloaded and installed VMware Workstation Pro.

Configured necessary settings for virtualization support.

2. Creating a New Virtual Machine
Created a new virtual machine.

Installed Ubuntu Server as the guest OS.

Allocated disk space, memory, and CPU cores.

3. Finding the IP Address of Ubuntu Server
Used terminal commands such as:

bash
Copy
Edit
ip addr show
or

bash
Copy
Edit
ifconfig
to obtain the server’s IP address.

4. Connecting via SSH from Windows
Installed and used SSH client (e.g., PuTTY or PowerShell).

Entered the Ubuntu server’s IP to establish a secure connection.

5. Accepting the Fingerprint
On first connection, accepted the SSH key fingerprint to verify authenticity.

6. Entering Password
Logged into the Ubuntu Server using the assigned credentials.

✅ Learning Outcomes
Understood the concept and importance of virtualization.

Learned to install and configure VMware Workstation Pro.

Successfully created and managed a virtual machine.

Established secure remote connections using SSH.
